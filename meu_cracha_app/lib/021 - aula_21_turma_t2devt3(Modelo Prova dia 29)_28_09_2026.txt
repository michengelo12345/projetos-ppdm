cp -r "/00 - turma t2dev-t3/04 - SEMESTRE/curso-ppdm/projetos_ppdm/meu_cracha_app" ~/projetos_ppdm/

cd ~/projetos_ppdm/meu_cracha_app

2. Edite o arquivo `lib/main.dart` no editor do terminal/SSH completando os **5 DESAFIOS** descritos nos comentários do código abaixo.

flutter run -d web-server --web-port 8080 --web-hostname 0.0.0.0

4. Verifique a tela final no navegador da sua bancada (`http://<IP_DO_DEBIAN>:8080`).

5. Ao finalizar, realize o commit e push no terminal para o seu GitHub e submeta o link e o `main.dart` no Google Forms.
